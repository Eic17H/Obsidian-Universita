## Routing all’interno dell’ internetworking (OSPF)
Un AS si puo’ suddividere in piu’ Aree.
Un AS puo’ avere un Area dorsale detta anche Area 0.
OSPF distingue:
1. Internal router
2. Border router (router tra aree di uno stesso AS)
3. Backbone router (router di dorsale)
4. Boundary router (router di confine verso altri AS)
