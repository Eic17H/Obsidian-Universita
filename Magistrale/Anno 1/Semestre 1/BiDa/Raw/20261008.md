NoSQL, not relational databases like SQL, not rows and columns, you include raw data, NoSQL runs distributedly through MongoDB and Cassandra. Cloud storage and computing is distributed. MapReduce isn't software, it's a methodology, and there are frameworks that implement it. But there is a software called HadoopMapReduce, it is software but it's not MapReduce, it implements MapReduce.
