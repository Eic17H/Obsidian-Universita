## 1

> Consider the following alternative approach to computing the convex hull of a set $P$ of $n$ points in the plane (*gift wrapping*). We start with the rightmost point: it is the first vertex $p_1$ of the convex hull. Now imagine a vertical line through $p_1$ and rotate it clockwise around $p_1$ until it hits another point $p_2$: this is the second vertex of the convex hull. We keep rotating the line, now around $p_2$, until it hits a point $p3$, and
> so on, until we return to $p_1$.
> 1. Give the pseudo-code of this algorithm, using only the orientation test seen in the course.
> 2. Prove that the algorithm can be implemented to run in $O(nh)$ time, where $h$ is the number of vertices of the convex hull. When is it faster than the $O(n \log n)$ algorithm seen in the course? *Hint*: The computational complexity is output sensitive.

### 1
- **Input**: a set $P$ of $n$ points.
- **Output**: the convex hull of $P$.
	1. Let $p_1$ be the rightmost point of $P$.
	2. Let $k=1$.
	3. Let $\theta_0 = 90°$ (vertical).
	4. While $p_{k+1} \neq p_1$:
		1. Let $l$ be the line passing trough $p_k$ at an angle $\theta _{k-1}$
		2. Let $l'$ be a line passing through $p_k$ and another point $p_r$ at an angle $\theta_k$ such that $p_r \neq p_j \forall j. 1 \leq j < k$ and $\theta_k - \theta_{k-1}$ is minimized.
		3. Let $p_{k+1} \in P$ be the point passing through $l'$ such that $p_k+1 \neq p_k$.
		4. Report the segment $p_kp_{k+1}$ as an edge of the convex hull.

With $0°$ being a horizontal line and a positive angle difference denoting a clockwise rotation.
### 2

1. $O(n)$
2. $O(1)$
3. $O(1)$
4. $O(h)$ times:
	1. $O(1)$
	2. $O(n)$ (check all the points in $P$).
	3. $O(1)$
	4. $O(1)$

$O(n) + O(h) \cdot O(n) = O(hn)$.
