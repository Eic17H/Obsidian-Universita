## Region growing

C'è un'alternativa, `grayqualcosa`, che fa la stessa cosa ma con un solo seme che scegliamo col mouse.

```MatLab
function [g, NR, SI, TI] = regiongrow(f, S, T)

f = double(f);
% if S is a scalar, obtain the seed image
if numel(S) == 1 % oppure isscalar(S)
	SI = f == S;
	S1 = S;
else
	SI = bwmorph(S, 'shrink', Inf);
	J = find(SI);
	S1 = f(J); % Array of seed values
end

TI = false(size(f));
for K = 1:length(S1)
	seedvalue = S1(K);
	S = abs(f - seedvalue) <= T;
	TI = TI | S;
end

[g, NR] = bwlabel(imreconstruct(SI, TI))

end
```

Se $S$ è uno scalare (`numel`), usiamo come semi le posizioni in cui i pixel hanno valore $S$. Altrimenti dobbiamo ridurre ogni punto seme a un pixel (`bwmorph`). `imreconstruct` si usa per riallargare le regioni.

## Watershed

Le linee spartiacque avranno valore $0$.

La trasformata watershed viene spesso usata insieme alla trasformata distanza, per quando si vuole segmentare un'immagine binaria con degli oggetti che si toccano.

Per ogni pixel, la trasformata distanza ci dice qual è la distanza dal pixel non-$0$ più vicino. Quindi morfologicamente, un cerchio nero diventa un cono. Quindi ribaltiamo il cono (invertiamo l'immagine) e la watershed ci rileva ogni cono separatamente. Però può separare i coni tra loro.
